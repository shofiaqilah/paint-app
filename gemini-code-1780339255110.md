# Prompt: UI Cleanup, Panel Positioning, and Rendering Bug Fix

## Role
Senior Frontend Developer & Canvas API Expert.

## Tugas 1: UI Cleanup (HTML/CSS)
Hapus elemen berikut dari `index.html` dan `style.css` agar tampilan bersih:
1. Hapus seluruh elemen grup **"Clipboard"** dan **"Image"**.
2. Hapus semua tombol simulasi window (Minimize, Full screen, Close).
3. Pastikan layout ribbon tersisa hanya tools, shapes, size, colors, dan "Show Transform".
4. Gunakan Flexbox untuk merapikan sisa elemen ribbon agar tidak ada gap/kosong setelah penghapusan.

## Tugas 2: Posisi Panel Transformasi (CSS)
Pindahkan `transform-panel` agar tampil di **sebelah kanan** tombol "Show Transform":
1. Gunakan `position: absolute` pada `#transform-panel`.
2. Targetkan posisinya agar menempel tepat di sisi kanan tombol "Show Transform" dengan margin kecil (misal: 10px).
3. Pastikan panel tersebut memiliki `z-index` tinggi agar terlihat menumpuk di atas elemen lain, namun tidak menutupi ribbon.
4. Jangan gunakan `position: relative` pada parent ribbon jika itu akan merusak layout tombol lainnya.

## Tugas 3: FIX BUG - Rendering Objek Menjadi Hitam (Critical)
Saat saya melakukan Transform (Shear, Scaling, Reflection), objek lingkaran/elips berubah menjadi **blok hitam solid**. Saya butuh kode perbaikan untuk ini:
1. **Pemeriksaan `ctx.fill()`**: Cari dan hapus semua perintah `ctx.fill()` atau `ctx.fillRect()` di dalam modul transformasi. Pastikan kode hanya menggunakan `ctx.stroke()`.
2. **State Management**: Pastikan sebelum melakukan transformasi, Anda memanggil `ctx.save()` dan setelah selesai memanggil `ctx.restore()` agar *style* (strokeStyle, lineWidth) tidak ter-overwrite oleh default canvas (yang biasanya hitam).
3. **Buffer Initialization**: Jika menggunakan `new ImageData(w, h)`, pastikan buffer tersebut di-*clear* secara transparan sebelum menggambar objek. Jika menggunakan kanvas sementara (offscreen canvas), pastikan `clearRect(0,0,w,h)` dipanggil sebelum menggambar ulang objek hasil transformasi.
4. **Logic Check**: Jangan pernah membiarkan algoritma transformasi melakukan perintah *fill* warna hitam.

## Output yang Diharapkan
1. **Block HTML**: Struktur ribbon yang sudah bersih tanpa Clipboard/Image/Window Controls.
2. **Block CSS**: Styling `.transform-panel` (Absolute positioning, styling card bersih) dan penyesuaian layout Ribbon.
3. **Block JavaScript**: Perbaikan fungsi di `js/algorithms/transformasi/` yang menangani rendering pasca-transformasi (pastikan tidak ada `ctx.fill()`).
