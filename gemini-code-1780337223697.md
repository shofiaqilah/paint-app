# Prompt: Implementasi Logika Transformasi untuk Lingkaran & Elips

## Masalah
Saat ini, logika transformasi saya sepertinya hanya mengandalkan manipulasi vertex/titik (berbasis array `lastVertices`). Ini bekerja baik untuk garis/shape poligon, tetapi merusak geometri atau tidak mendukung transformasi yang tepat untuk **Lingkaran** dan **Elips** (karena lingkaran/elips didefinisikan oleh parameter `cx, cy, rx, ry` bukan sekadar kumpulan titik).

## Tujuan
Saya ingin sistem transformasi di `js/algorithms/transformasi/` mampu mendeteksi tipe bentuk:
1. Jika bentuk adalah **Poligon/Garis**: Gunakan transformasi matriks vertex.
2. Jika bentuk adalah **Lingkaran/Elips**: Lakukan modifikasi pada parameter geometri (`center`, `radiusX`, `radiusY`) secara langsung untuk menjaga akurasi bentuk.

## Tugas Teknis
1. **Pendeteksian Tipe Shape:**
   - Tambahkan logika di `main.js` atau modul transformasi untuk memeriksa tipe objek yang dipilih.
   - Jika tipe adalah 'circle' atau 'ellipse', jangan gunakan transformasi vertex berbasis array.

2. **Logika Transformasi (Math):**
   - **Translasi:** Ubah koordinat `cx` dan `cy`.
   - **Scaling:** Ubah nilai `radiusX` dan `radiusY`.
   - **Rotasi (Khusus Elips):** Tambahkan support untuk parameter `rotation` (jika memungkinkan) atau beri tahu saya cara menangani rotasi pada elips secara geometris.

3. **Integritas Geometri:**
   - Pastikan setelah transformasi, fungsi `render` tetap menggambar shape dengan fungsi `midpoint_circle.js` atau `midpoint_ellipse.js` agar kualitas kurva tetap halus (bukan hasil render polygon hasil transformasi).

## Output yang Diharapkan
- Berikan logika pemisahan (branching) dalam fungsi transformasi untuk menangani tipe bentuk yang berbeda.
- Berikan contoh fungsi `transformCircle(params, matrix)` yang mengembalikan parameter baru, bukan mengubah array vertex.
- Pastikan kode ini bisa diintegrasikan dengan sistem `lastVertices` saya tanpa merusak sistem history Undo/Redo.

## Constraints
- Gunakan pendekatan parametrik (bukan vertex array) untuk lingkaran dan elips.
- Kode harus bersih dan bisa langsung disisipkan ke dalam arsitektur `js/algorithms/transformasi/`.
