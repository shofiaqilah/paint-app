# Prompt: Refactor Panel Transformasi (Positioning)

## Masalah Utama
Saat ini, panel transformasi muncul di **bawah** tombol "Show Transform". Saya ingin mengubahnya agar muncul di **sebelah kanan** tombol "Show Transform" secara rapi.

## Tujuan
Memindahkan posisi `transform-panel` agar sejajar secara horizontal dengan tombol pemicunya (Show Transform) di dalam Ribbon.

## Instruksi Teknis
1. **Parent Container (Ribbon):**
   - Pastikan container tombol "Show Transform" (atau wrapper ribbon-nya) memiliki `position: relative;`.

2. **Panel Transformasi (`transform-panel`):**
   - Gunakan `position: absolute;`.
   - Atur posisi `left: 100%;` (atau `calc(100% + 10px);` untuk memberikan sedikit jarak).
   - Atur `top: 0;` agar sejajar dengan bagian atas tombol.
   - Pastikan `z-index` cukup tinggi agar panel tidak tertutup elemen ribbon lainnya.

3. **Layout:**
   - Gunakan `display: flex;` pada wrapper utama jika perlu, atau cukup manfaatkan CSS Absolute Positioning agar panel tidak menggeser layout ribbon saat dibuka.

## Harapan Output
- Berikan potongan kode CSS yang sudah diperbarui untuk `#transform-panel`.
- Berikan instruksi jika ada penyesuaian kecil pada HTML agar posisi relatifnya benar.
- Pastikan tidak ada "jumps" atau pergeseran pada layout Ribbon saat panel dibuka atau ditutup.

## Constraints
- Jangan mengubah logika JS.
- Hanya fokus pada penyesuaian CSS posisi agar panel "menempel" di sebelah kanan tombol.
- Jika ada *arrow* kecil pada panel (seperti *tooltip*), tolong sertakan kodenya agar terlihat lebih profesional.
